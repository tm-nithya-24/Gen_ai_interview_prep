what is sql?
SQL is a domain-specific language used in programming and designed for managing data held in a relational database management system (RDBMS), or for performing computations on data in a streaming fashion. SQL stands for Structured Query Language.

what is rdbms?
RDBMS stands for Relational Database Management System. It is a type of database management system that stores and manages data in a relational format, i.e., data is organized in tables with rows and columns.

what is a table?
A table is a collection of related data organized in rows and columns.

what is a row?
A row is a horizontal collection of related data in a table. It is also known as a record or a tuple.

what is a column?
A column is a vertical collection of related data in a table. It is also known as a field or an attribute.

what is a primary key?
A primary key is a column or a set of columns that uniquely identifies each row in a table.

what is a foreign key?
A foreign key is a column or a set of columns that refers to the primary key of another table. It is used to establish a relationship between two tables.

what is a join?
A join is a clause used to combine rows from two or more tables based on a related column between them.

what is an index?
An index is a data structure that improves the speed of data retrieval operations on a database table.

what is a view?
A view is a virtual table based on the result-set of an SQL statement. It is a way to simplify complex queries and to provide a layer of abstraction between the user and the database.

what is a stored procedure?
A stored procedure is a prepared SQL code that can be stored in the database and executed multiple times. It is used to perform a specific task or a set of tasks.

what is a trigger?
A trigger is a special type of stored procedure that is automatically executed when a specific event occurs in the database, such as an insert, update, or delete operation.

what is a cursor?
A cursor is a database object that allows you to iterate over the rows of a result set one by one. It is used to perform row-by-row processing of data.

what is a transaction?
A transaction is a sequence of SQL operations that are treated as a single unit of work. It is used to ensure data consistency and integrity.

what is normalization?
Normalization is the process of organizing data in a database to reduce data redundancy and improve data integrity.
